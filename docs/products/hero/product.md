# Adjustable Magnetic Posture Corrector

## Description

The Adjustable Magnetic Posture Corrector is a discreet back support brace designed to encourage a more upright posture during daily wear. Its adjustable strap system helps create a secure, personalized fit, while the lightweight construction is made for office use, commuting, light activity, and long stretches at a desk.

Built to stay low-profile under clothing, it offers a clean, minimal look without drawing attention. The unisex fit and range of sizes make it suitable for a broad set of users looking for a straightforward posture support solution.

## Product Data

- Product type: Posture corrector / back support brace
- Target use: Daily posture support for office, home, and travel
- Fit: Unisex, adjustable
- Materials: Neoprene, elastic fabric
- Colors: Black, White
- Package contents: 1 posture corrector
